Come pubblicare

    
    
      
  1. Scarica risposte.json con il pulsante qui sopra.
    2. 
      
  2. Su GitHub apri il repository, entra nella cartella data e scegli Add file → Upload files.
    3. 
      
  3. Carica il nuovo risposte.json (sostituisce il vecchio) e conferma con Commit changes.
    4. 
      
  4. Dopo un paio di minuti l'app mostra le nuove risposte. Non serve cambiare altro.
    5. 
    

    
Regole del file Excel: un foglio per domanda (il primo è la Domanda A, il secondo la B), una riga di intestazione con le colonne Risposta… e Stato, la domanda nella cella A2. Vengono mostrate le risposte con stato Attiva, Nuova o senza stato; quelle Da rivedere ed Escludere restano nell'archivio ma non escono nell'app. I testi vengono copiati esattamente come scritti, con un'unica eccezione: «Birrario» diventa sempre «Birraio».
